Kyrgyz City — запуск на Windows (исправленная версия 0.1.1)

1. Нажмите правой кнопкой по ZIP-архиву и выберите «Извлечь всё».
2. Откройте распакованную папку kyrgyz-city.
3. Дважды нажмите start.bat. Если расширения скрыты, он может называться start;
   его тип — «Пакетный файл Windows».
4. Подождите. В первый раз устанавливаются библиотеки Python.
5. Игра сама откроется в браузере, когда сервер будет готов.
6. Оставьте окно запуска открытым во время игры. Остановка — Ctrl+C.

Если браузер не открылся, используйте адрес, напечатанный в окне запуска.
Обычно это http://127.0.0.1:8000/, но при занятом порте адрес может отличаться.

Если появилась ошибка:
- окно останется открытым;
- ошибки сервера сохраняются в launch.log рядом со start.bat;
- ошибки установки библиотек сохраняются в setup.log;
- пришлите текст ошибки или скриншот окна. Журналы сами никуда не отправляются.

Нужен Python 3.11 или новее; рекомендуем Python 3.12.
При установке Python включите «Add Python to PATH».
Полная инструкция — в README.md.
