# Проверки первой версии

Проверено 8 ноября 2026 года (дата клиента, Asia/Bishkek).

## Пройдено

- `npm run build`: TypeScript-проверка и production-сборка Vite.
- `npm test`: 16 тестов frontend, все проходят.
- `.venv/bin/python -m pytest -q`: 15 тестов backend, все проходят.
- Реально запущен Uvicorn на `http://127.0.0.1:8000`; HTTP-запрос `/api/health` вернул `status: ok` и числа 160/18/10/10/10.
- HTTP-запрос `/lessons/en/home?text=1` вернул английский урок со словами Window / Терезе без React module-скрипта.

Всего 31 автоматический тест. `npm test` не запускает полноценный браузер: UI проверяется в jsdom, а 3D Canvas заменён тестовой сценой. Считать эти проверки визуальным или аппаратным тестом нельзя.

### Что проверяют тесты

Backend: маршруты главной, игры, трёх учебных направлений, проекта и конфиденциальности; существование и отдача собранных файлов; API-коллекции и фильтры; 404 и 422; отсутствие фиктивной оценки произношения; ссылки между словами, локациями, диалогами и миссиями; завершимость каждой правильной цепочки диалога; SEO с заданным доменом и без него; заголовки безопасности.

Frontend: сохранение и восстановление персонажа и XP; повреждённый localStorage; защита от повторного начисления; порядок шагов и завершимость всех 10 миссий; интервалы повторения; недоступность стен и границ карты; маршруты к каждому из 10 входов и обход здания.

UI: создание персонажа, вход/выход из дома, неправильная реплика с объяснением, полный домашний диалог, посещение базара, покупка воды, возвращение домой, завершение первой миссии с 110 XP и восстановление после перемонтирования; английский интерфейс и избранное; прохождение всех слов одного урока с исправлением ошибки и сборкой предложения.

Аудио: неподдерживаемый браузер, отказ микрофона, начало/остановка записи, локальный object URL для плеера, освобождение tracks и URL при закрытии, отсутствие запросов отправки голоса и отсутствие выдуманных оценок. MediaRecorder и микрофон в этих тестах заменены управляемыми тестовыми объектами.

## Ограничения проверки

В управляемой среде `ccarenv_b64_Y2NhcmVudl9kNWZlMzZkN2I4NDQ4MTkxYTg1NTE1YTRkNjEzMTg3ZA` подключён remote desktop (`enabled: true`, `state: unknown`), но инструменты `cua_repl.js`/browser и открытие Desktop не предоставлены этой сессии. После готовности среды доступность инструментов проверена повторно. По правилам среды не устанавливался обходной браузер. Поэтому **реальный WebGL-рендер, скриншоты, FPS, фактический микрофон и мобильная раскладка в браузере не проверены**.

Тесты геометрии подтверждают проходимость маршрутов, но не качество картинки и жестов камеры. Скрипт Linux и ручной Uvicorn проверены в Linux; запуск `start.bat` на Windows и сборка Docker не выполнялись. Vite предупреждает о размере чанка Three.js (больше 500 kB до сжатия); это библиотека 3D. Модуль игры загружается отдельно, а текстовые страницы не требуют Canvas. В pytest есть предупреждение устаревшего алиаса AnyIO внутри Starlette TestClient; ошибок тестов нет.

## Как повторить автоматические проверки

Из корня проекта:

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
cd frontend
npm ci
npm run build
npm test
cd ..
.venv/bin/python -m pytest -q
```

На Windows используйте `.venv\Scripts\python.exe`. Тесты backend требуют уже собранной папки `static/app`.

## Обязательная ручная проверка перед публичным показом

1. Откройте главную в Chrome/Edge и Firefox при 1440×900 и 1280×720. Проверьте читаемость кыргызских Ң ң Ө ө Ү ү.
2. Пройдите создание персонажа, движение WASD/стрелками, остановку у стены, маршрут вокруг здания, вращение/масштаб/панорамирование и центрирование камеры.
3. Посетите все 10 локаций, откройте предметы и NPC. Пройдите первую миссию строго по шагам и убедитесь, что повторное прохождение не добавляет повторную базовую награду.
4. Включите русское, английское и кыргызское направления. Проверьте все разделы, учебные заметки, сообщения об ошибках и сохранение XP при смене языка.
5. Разрешите реальный микрофон, произнесите слово и прослушайте запись. Проверьте отказ разрешения, отключённое устройство, закрытие окна во время записи и автоматическую остановку через 30 секунд. Голос не должен появляться во вкладке Network как отправляемый запрос.
6. Обновите страницу, закройте и заново откройте браузер. Проверьте сцену, словарь, XP, уроки и миссии.
7. Проверьте портретный экран 390×844 и 320×568, сенсорные стрелки, карту, модальные окна и клавиатуру ввода. Для очень маленькой высоты игровая область допускает прокрутку.
8. Отключите WebGL или выберите обычные уроки. Откройте HTML-режим и отключите JavaScript: слова и примеры должны остаться доступны.
9. Проверьте Tab, Shift+Tab и Esc, перевод фокуса в модальное окно и возврат к открывшей его кнопке.
10. На слабом ноутбуке измерьте FPS, выберите низкое качество и при необходимости отключите анимацию. Подтвердите, что запись голоса работает после публикации только через HTTPS.
