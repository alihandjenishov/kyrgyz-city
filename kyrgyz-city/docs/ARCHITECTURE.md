# Устройство проекта

```text
main.py                         FastAPI, страницы, API, SEO, заголовки безопасности
backend/content.py              загрузка и базовая валидация каталога
backend/content/*.json          лексика, уроки, локации, графы диалогов, миссии
templates/index.html            единая серверная оболочка React
         /lessons.html          индексируемый HTML из того же каталога
frontend/src/App.tsx            разделы приложения и связь UI с прогрессом
frontend/src/components/        окна, упражнения, карточки, мини-карта
frontend/src/game/Models.tsx    процедурные здания, мебель, люди, детали города
frontend/src/game/CityScene.tsx сцена, интерьер, кадры движения, камера
frontend/src/game/shared.ts     описание предметов и сенсорное управление
frontend/src/game/navigation.ts коллизии и поиск пути
frontend/src/state/progress.ts  сохранение, XP, шаги миссий и интервалы повторения
frontend/src/audio/Recorder.tsx жизненный цикл микрофона и временного аудио
frontend/src/localization/      централизованные тексты трёх языков
frontend/src/styles.css         адаптивный интерфейс и оформление
static/app/                    результат Vite-сборки, включён в ZIP
```

Выбран React/Three.js, потому что он объединяет доступный обычный UI с 3D и не требует игрового движка на компьютере пользователя. React Three Fiber описывает сцену, Drei предоставляет камеру, управление и HTML-маркеры. FastAPI остаётся единственным сервером и источником учебного контента. Tailwind, SQLAlchemy и внешняя авторизация не понадобились: отдельная CSS-система и локальный гостевой прогресс проще для текущего объёма.

## Движение и камера

Город непрерывный. Внутренняя сетка поиска пути имеет шаг около одного метра и не рисуется на земле. Алгоритм A* обходит прямоугольные контуры зданий. Движение с клавиатуры проверяет столкновения по каждой оси, чтобы персонаж мог скользить вдоль стены. В интерьере коллизии учитывают мебель; сцена ограничена стенами комнаты. Декоративные деревья, автомобили и фонтан в городской сцене не являются физическими препятствиями. Это ограничение текущей упрощённой физики.

Главная позиция хранится в Three.js ref и обновляется каждый кадр. В React/сохранение передаётся только изменившаяся позиция с интервалом около 300 мс. Когда начинается ходьба, камера мягко следует за игроком; пользовательское вращение или панорамирование временно отключает следование. Нажатие прицела включает его снова. Изменение масштаба — через OrbitControls.

3D-модуль загружается динамически. Текстовые уроки не создают Canvas. Качество регулирует плотность пикселей, сглаживание, наличие теней и их разрешение; геометрия не меняется. Полноценный мобильный FPS-профиль ещё нужно измерить. Модели не используют скачиваемые текстуры или GLB.

## Учебные события и XP

- Новое изученное слово: +5 XP.
- Первое полное завершение урока: +30 XP.
- Первое завершение диалога: +25 XP.
- Завершение миссии: её `xp` (в стартовом каталоге 60).
- Каждые 150 XP — новый игровой уровень.

Повторное событие не даёт ту же базовую награду второй раз. При этом оно может выполнить текущий шаг активной миссии. Миссии принимают только следующий ожидаемый тип события и ID цели, поэтому нельзя пропустить покупку или получить награду за посещение другого здания.

Расписание повторений хранится для каждого слова: время последнего ответа, число успехов, ошибок и следующая дата. Успех увеличивает интервал до 1/3/7/14/30 дней. Ошибка сбрасывает ступень и назначает повторение через 10 минут. Это простой учебный алгоритм, не полная реализация SM-2.

## Хранение и API

Серверный каталог read-only: файлы меняет редактор проекта, а не посетители. Сохранение версии 1 хранится в localStorage, проверяется при чтении, повреждённые значения заменяются безопасными начальными. Секретов, аккаунтов, серверной базы пользователей, прогресс-API и синхронизации нет. В будущем слой хранения можно заменить PostgreSQL и авторизацией без изменения ID контента; сам формат JSON не зависит от конкретной СУБД.

API доступны по `/api/locations`, `/api/lessons`, `/api/vocabulary`, `/api/dialogues`, `/api/quests`. Для локаций, уроков и диалогов есть маршруты по ID; неизвестный ID даёт 404. Словарь поддерживает фильтры `category`, `location`, `level`, `q`. `/api/health` возвращает версию и фактические размеры каталога. Полная OpenAPI-схема — `/docs`.

`POST /api/verify-pronunciation` принимает `{ "expected_text": "Өрүк", "language": "ky" }`. Пока он только сообщает `not_available`, `score: null`. Он не принимает аудиофайл и не имитирует оценку. Будущая интеграция требует отдельного, явно согласованного потока передачи аудио, ограничения размера/длительности, проверенной поддержки кыргызского ASR и отдельной модели фонетической оценки. Правильная транскрипция не доказывает правильное произношение.

## Приватность

MediaRecorder создаётся только после нажатия кнопки и getUserMedia. После остановки или закрытия окна освобождаются все tracks, таймеры и object URL. Запись длится максимум 30 секунд. Отслеживаются отказ разрешения, отсутствие устройства, неподдерживаемое API и пустой blob. Громкость речи или фонетика автоматически не анализируются; полностью тихая, но непустая запись может сохраниться для самостоятельного прослушивания.

React экранирует пользовательское имя и строки контента. Не применяется `dangerouslySetInnerHTML`. Jinja2 экранирует текст серверных страниц. Pydantic валидирует каталог слов и pronunciation-запрос. Камера запрещена Permissions-Policy, микрофон разрешён только собственному origin. Никакой аналитики, внешних шрифтов, трекеров или автоматической отправки голоса нет.
