# Происхождение ресурсов

В проекте нет скачанных изображений, музыки, голосов, текстур или сторонних моделей зданий. Вся геометрия города, мебели и персонажей создаётся кодом проекта. Превью мест в карточках нарисованы CSS. Значок favicon создан SVG-кодом. Используются системные шрифты Segoe UI/Arial/sans-serif; внешний шрифт с сервера не загружается.

Иконки: lucide-react (ISC). Основные библиотеки: React/React DOM (MIT), Three.js (MIT), React Three Fiber (MIT), Drei (MIT), FastAPI (MIT), Uvicorn (BSD-3-Clause), Jinja2 (BSD-3-Clause), Pydantic (MIT), Vite (MIT), TypeScript (Apache-2.0). Полный список точных frontend-зависимостей зафиксирован в `frontend/package-lock.json`, Python — в `requirements*.txt`. Тексты лицензий зависимостей находятся в их пакетах; файл `THIRD_PARTY_NOTICES.txt` собирается из установленных frontend-пакетов вместе с поставкой.

Учебные слова и примеры — стартовый авторский набор проекта, не лицензированный корпус и не официальный учебник. Не утверждается, что их проверил носитель. При добавлении материалов извне фиксируйте точный URL, автора, тип лицензии, дату получения и нужную атрибуцию. Для голоса отдельно получите разрешение на использование записи в публичном образовательном приложении.
