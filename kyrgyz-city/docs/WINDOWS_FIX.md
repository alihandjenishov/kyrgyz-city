# Исправление запуска Windows — 0.1.1

В первоначальном приложении JSON-каталог читался через `Path.read_text()` без указания кодировки. При русской системной кодировке Windows CP1251 чтение файла UTF-8 обрывается с `UnicodeDecodeError`. Ошибка воспроизведена с имитацией CP1251; после исправления каталог загружается с правильными кыргызскими буквами. Это подтверждённая ошибка кода, но без журнала с компьютера пользователя нельзя утверждать, что именно она была единственной причиной его сбоя.

Все JSON-файлы теперь явно читаются как UTF-8. В Windows-запуске дополнительно включён UTF-8 для Python и вывода. Файл `start.bat` записан с окончаниями строк CRLF. В нём появилась обязательная остановка окна после завершения сервера или ошибки.

Модуль `scripts/launch.py` загружает приложение с явной папкой проекта, сохраняет сообщения и traceback в `launch.log`, привязывается только к loopback и выбирает свободный порт из 8000–8010. Браузер открывается только после готовности Uvicorn и успешной проверки `/api/health`. Локальная проверка состояния обходит настройки HTTP-прокси. При ошибках установки подробности остаются в `setup.log`.

Добавлены 7 проверок запуска: системная кодировка CP1251, занятый порт, отсутствие свободных портов, ожидание готовности перед открытием браузера, отмена запуска, реальный HTTP-запуск из другой рабочей папки и сохранение traceback при неудачном импорте приложения. Все проверки запускаются в Linux; реальное выполнение BAT-файла на Windows и запуск на компьютере пользователя ещё требуют подтверждения. Полный backend-набор содержит 15 тестов. Frontend не изменялся; его предыдущие 16 тестов и сборка остаются применимы.

При повторной проблеме попросите пользователя прислать `launch.log` или скриншот сохранённого окна, прежде чем предполагать причину. Журналы автоматически никуда не отправляются и не входят в распространяемый ZIP.
