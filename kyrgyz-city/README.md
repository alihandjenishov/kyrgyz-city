# Kyrgyz City — кыргызский через приключение

Обновление 0.1.1: исправлено чтение UTF-8-файлов на Windows. Новый `start.bat` сохраняет ошибки, оставляет окно открытым и открывает браузер после готовности игры. Если порт 8000 занят, выбирается свободный порт рядом; используйте адрес, напечатанный в окне. Подробности — в `docs/WINDOWS_FIX.md`.

Первая игровая версия бесплатного образовательного проекта. Python/FastAPI обслуживает React/TypeScript и процедурный город Three.js. Игра не требует аккаунта, не содержит рекламы и платежей. Публикация в интернете не выполнялась.

## Что создано

| Содержимое | Фактически реализовано |
| --- | --- |
| Учебные локации | 10: дом, школа, базар, больница, библиотека, кафе, парк, остановка, банк, гостиница |
| Внутренние сцены | 8 помещений; парк и остановка открываются как отдельные открытые сцены |
| Уроки | 18, все доступны без 3D |
| Слова и выражения | 160, с переводами на русский и английский и кыргызскими примерами |
| Собеседники | 10 именованных NPC с учебными диалогами; ещё 6 фоновых пешеходов |
| Диалоги | 10, каждый из 3 шагов; неправильная реплика оставляет игрока на текущем шаге и объясняет ошибку |
| Миссии | 10, по 3–4 последовательных шага |
| Типы заданий | Выбор перевода в обе стороны, сборка предложения, ввод кыргызского слова, поиск предмета в доме, разговор с NPC |
| Языки интерфейса | Русский, английский, кыргызский |
| Прогресс | XP, уровень, слова, уроки, разговоры, посещения, миссии, избранное, достижения, расписание повторений |

Город включает дороги, тротуары, переходы, разные здания, деревья, фонари, скамейки, автомобили, горы, фонтан, движущихся пешеходов. Персонаж ходит с клавиатуры, с сенсорных кнопок и по выбранному маршруту. Стены зданий блокируют путь. Камера вращается, масштабируется и следует за персонажем. Во внутренних сценах есть тематические предметы, NPC и доступные кнопки для всех взаимодействий.

Это первая версия, а не завершённая программа A0–B1. Дом — общая комната с мебелью и кухонным уголком, без четырёх отдельных комнат. Переводы и диалоги написаны для стартовой редакции и **не проверены преподавателем — носителем языка**. A0/A1 — ориентиры сложности, не официальная сертификация.

Записей носителей сейчас нет. Кнопка озвучки честно сообщает об этом. Запись и прослушивание собственного голоса реализованы браузерным MediaRecorder. Автоматической оценки произношения нет: API возвращает `not_available`, `score: null`. Голос на сервер не отправляется.

## Быстрый запуск на Windows

1. Распакуйте архив целиком в удобную папку, например `Documents\kyrgyz-city`. Не запускайте файлы прямо внутри ZIP.
2. Установите Python 3.11 или новее с официального сайта python.org. В установщике включите **Add Python to PATH**.
3. Дважды нажмите `start.bat` в папке игры.
4. При первом запуске потребуется интернет для установки Python-библиотек. Скрипт создаст виртуальное окружение `.venv`, не изменяя системные библиотеки.
5. Дождитесь запуска: браузер откроется автоматически. Если этого не произошло, откройте адрес из окна запуска — обычно **http://127.0.0.1:8000**. Оставьте окно запуска открытым во время игры. При ошибке оно больше не закрывается, а подробности сохраняются в `launch.log` (ошибки установки — в `setup.log`).
6. Чтобы остановить сервер, нажмите **Ctrl+C** в его окне. Для повторного запуска снова откройте `start.bat`.

В архив входит готовая сборка интерфейса. Node.js нужен только при изменении frontend или отсутствии папки `static/app`: установите Node.js 22.12+ с nodejs.org, затем повторите запуск. Скрипт выполнит сборку автоматически.

Если Windows показывает предупреждение о скачанном файле, сначала проверьте содержимое `start.bat`: он только создаёт виртуальное окружение, устанавливает зависимости проекта, при необходимости собирает frontend и запускает локальный сервер.

## Запуск на Linux/macOS

Нужен Python 3.11+. В терминале перейдите в распакованную папку:

```sh
chmod +x start.sh
./start.sh
```

Откройте http://127.0.0.1:8000. Остановка — Ctrl+C. Повторный запуск — `./start.sh`.

Если отсутствует модуль `venv`, установите его средствами вашей системы. Скрипты не требуют прав администратора. Порт 8000 должен быть свободен. При необходимости запускайте вручную с `--port 8001` и открывайте соответствующий адрес.

## Ручной запуск и разработка

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
cd frontend
npm ci
npm run build
cd ..
.venv/bin/python -m uvicorn main:app --reload
```

На Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`. Команда `--reload` автоматически перезапускает backend после правок. После изменения frontend повторяйте `npm run build` и обновляйте страницу.

Для frontend с горячим обновлением запустите FastAPI на 8000 и `npm run dev` из `frontend` во втором терминале. Vite проксирует `/api` на FastAPI. Открывайте напечатанный Vite адрес. В обычном запуске нужен только один FastAPI-сервер, никаких дополнительных сервисов нет.

Адрес 127.0.0.1 означает компьютер, на котором запущен сервер. Сервер, запущенный в облачной рабочей среде Codex, не появляется автоматически на вашем компьютере. Для самостоятельного запуска скачайте и распакуйте проект.

## Как играть

1. Выберите язык в правой части верхней панели: русский → кыргызский, English → Kyrgyz или кыргызская речевая практика.
2. Нажмите «Начать приключение». Введите любое игровое имя, выберите куртку или жилет и цвет. Настоящее имя не нужно.
3. Персонаж появляется у дома. WASD или стрелки двигают его по миру. На телефоне используйте экранные стрелки. Можно нажать на свободное место или на подпись здания: персонаж найдёт путь к нему.
4. Мышью вращайте и перемещайте камеру: левая кнопка — вращение, правая — панорамирование, колесо — масштаб. На сенсорном экране работают жесты OrbitControls. Кнопка прицела возвращает камеру к игроку.
5. У входа появляется кнопка «Войти». Нажмите её или E. Надпись здания строит маршрут, а вход доступен возле двери.
6. В помещении нажимайте на предметы с маркером «+» или на названия под сценой. Откроются кыргызское слово, перевод и пример. «Запомнить слово» добавляет его в прогресс и даёт 5 XP один раз.
7. Нажмите имя NPC или E внутри помещения. Выберите ответы из предложенных реплик. При ошибке прочитайте объяснение и попробуйте ещё раз. Завершённый диалог даёт 25 XP один раз.
8. У дома можно включить «Найди предмет в комнате»: выберите окно — «Терезе». Кнопки под сценой в этом режиме скрывают названия, чтобы не выдавать ответ.
9. Активная миссия показана справа. Сначала поговорите с Айжан, затем посетите базар, купите воду в разговоре с Айгүл и вернитесь домой. За последовательное выполнение получите 60 XP. Остальные миссии выбираются в разделе «Миссии»; действия отслеживаются для одной активной миссии.
10. Нажмите «На улицу», чтобы выйти. Раздел «Уроки» даёт доступ ко всем темам без 3D. Каждый урок проверяет все его слова и содержит упражнение на порядок слов. Полное завершение даёт ещё 30 XP один раз.
11. В словаре можно искать слова, отмечать избранное и выбирать изученные слова или слова для повторения. После успешного ответа интервалы составляют 1, 3, 7, 14 и 30 дней. После ошибки повторение назначается через 10 минут. Дата следующего повторения показана в карточке слова.
12. В разделе «Речевая практика» выберите слово со звуками Ө, Ү или Ң. Нажмите «Записать голос», разрешите микрофон, произнесите слово, остановите запись и прослушайте. Запись ограничена 30 секундами. Удаление, смена слова или закрытие карточки освобождает запись. Никаких автоматических процентов точности нет.
13. Каждый 150 XP повышает игровой уровень. Уровень игрока не означает языковую сертификацию. Ошибки не отнимают жизнь и не ограничивают обучение.
14. Прогресс автоматически сохраняется в localStorage этого браузера: имя, внешний вид, место в городе, слова, уроки и миссии. Возвращайтесь с того же браузера и адреса. Очистка данных браузера, приватный режим и другой домен могут удалить или отделить сохранение. В настройках есть экспорт JSON, параметры графики и сброс.

Esc закрывает открытое окно; в игре без открытого окна Esc открывает настройки. Окна поддерживают Tab и удерживают клавиатурный фокус. Для слабого устройства выберите низкое качество или используйте «Уроки». Если WebGL недоступен, интерфейс предлагает обычные уроки. Кнопка HTML в разделе уроков открывает серверные текстовые страницы без JavaScript и 3D.
